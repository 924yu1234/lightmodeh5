### start dev
```
npm install && npm start
```
### start dev within wallet (1)
```
1. index_dev.tsx change walletUrl if your local wallet port is not 10004
2. wallet -> public/index.html set TRADE_URL to your local trade url (for example http://localhost:3000/)
3. npm run startWithWallet
4. open the trade dev url and it will redirect to the local wallet page

```

### start dev within wallet (2)
```
1. Copy the script and link tags from the source code of the wallet online project to index.html (example index_wallet.html)
2. npm start

```
